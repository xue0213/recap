# Kernel Index

The model adapters and compatibility kernels are implemented in
`rebuttal/baselines/baseline_models.py` and
`rebuttal/baselines/baseline_common.py`.

The OFO model, sparse-structure, label-vault, runner, and audit kernels are in
`rebuttal/ofo_baselines/models.py`, `common.py`, `runner.py`, and
`analysis.py`.
